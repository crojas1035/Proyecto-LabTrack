# Proyecto-LabTrack

## Descripción
LabTrack es una aplicación web para administrar laboratorios educativos, equipos, solicitudes de uso y reportes de fallas.

## Objetivo
Facilitar el control de recursos y mejorar la organización de los laboratorios mediante una plataforma centralizada.

## Tecnologías previstas
- Java
- Spring Boot
- Bootstrap
- Base de datos SQL
- Git y GitHub
